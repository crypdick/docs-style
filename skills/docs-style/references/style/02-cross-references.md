# Cross-references and linking

## Strategy

* **Context first:** Include brief definitions or steps in the text so readers can follow the explanation without opening another page.
* **Selectivity:** Link only to relevant information. Avoid duplicate links on the same page.

## Link text

* **Descriptive:** Use the destination page title or a descriptive noun phrase.
* **No "click here":** Avoid "click here", "this document", or bare URLs (except in legal docs).
* **Abbreviations:** If the text has an abbreviation, include the full term in the link text to help readers search and scan.
  * *Recommended:* "Google Kubernetes Engine (GKE)"
* **Code items:** If linking to a command or flag, include the description in the link text if possible.
  * *Recommended:* "...set the hostname with the `--hostname` flag."

## Formatting

* **Introduction:** Explain why the link is useful, or use a short lead-in such as "For more information, see Link Text."
* **Punctuation:** Place punctuation outside the link tags.
* **Tabs and downloads:**
  * Open links in the same tab.
  * If a link behaves unexpectedly (e.g., downloads a PDF), mention it in the text: "Download the security features PDF."
* **Quotes and italics:** Do not use quotes for link text. Use italics for titles of full-length works (books) that aren't linked.
